# 3D GOKIL AI MUSIC FACTORY V1

## Deploy lewat HP
1. Buat repository GitHub baru bernama `3d-gokil-ai-music-factory`.
2. Upload `app.py`, `requirements.txt`, dan `README.md` ke root repository.
3. Buka Streamlit Community Cloud, pilih **New app**.
4. Pilih repository, branch `main`, file `app.py`, lalu Deploy.

Simpan project ini di repository terpisah dari dashboard 3D GOKIL LIVE agar aplikasi LIVE tidak terganggu.

V1 menyediakan draft lirik, Suno Style, avoid prompt, artwork prompt LONG/SHORT, metadata YouTube, dan export JSON. Versi ini memakai template lokal, bukan model AI dan tidak memerlukan API key. Hasil perlu diedit. Integrasi AI, image generation, analisis audio, FFmpeg dan upload YouTube direncanakan untuk versi berikutnya.
